# SkillMesh Frontend 🚀

Frontend codebase for **SkillMesh** – a dynamic and intuitive platform designed to host events, facilitate smart team formation, enable project submissions, and streamline talent recruitment.

## ✨ Overview

SkillMesh aims to bridge the gap between opportunities and talent by offering:

- 📁 Multi-round project submissions
- 🧠 Resume-based registration and screening
- 🛠️ Real-time mentorship support
- 🧑‍💼 Recruitment portal for hiring teams
- 🏆 Gamified participation and engagement

This repository contains the user-facing interface of SkillMesh built with modern web technologies.

## ⚙️ Tech Stack

- **Framework:** React.js
- **Styling:** Tailwind CSS
- **Routing:** React Router
